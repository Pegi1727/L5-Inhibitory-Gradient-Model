# Multilingual Inhibitory Gradient Model (L5 Acquisition Study)
‌
This repository contains the dataset, analysis scripts, and conceptual frameworks associated with the study of **cross-linguistic interference in higher-order multilingualism (L5 acquisition)**.
‌
## 📌 Project Overview
The study investigates a theoretical paradox: **Why can a dominant L3 be easier to suppress than a developing L4?**
‌
Based on a case study of a multilingual speaker (L1 Azerbaijani, L2 Persian, L3 English, L4 Russian, L5 Spanish), this project proposes the **Inhibitory Gradient Model**. Our findings suggest that developmental stability, rather than simple dominance, determines the level of inhibitory effort required during language production.
‌
## 🚀 Key Features
- **Inhibitory Gradient Model:** A new conceptual framework for understanding language control in speakers with 4+ languages.
- **Intrusion Dataset:** Quantitative distribution of lexical, morphosyntactic, and phonological intrusions.
- **Visualizations:** Journal-ready diagrams (generated via Python/Matplotlib) showing the asymmetry between L3 and L4 interference.
‌
## 📊 Findings Summary
- **Russian (L4):** Accounted for ~91% of total intrusions.
- **English (L3):** Minimal interference, despite higher proficiency.
- **Inhibitory Paradox:** Highly entrenched languages (L3) show higher inhibitory stability than unstable systems (L4).
‌
## 📁 Repository Structure
- `/data`: Transcripts and coded intrusion counts.
- `/plots`: Figures and conceptual diagrams (including the Inhibitory Gradient Model).
- `/scripts`: Python scripts for data visualization and statistical overview.
- `/manuscript`: Abstract and supplementary materials.
‌
## 🛠 Tech Stack
- **Data Analysis:** Python (Pandas, Matplotlib, Seaborn)
- **Linguistic Framework:** Psycholinguistics, Inhibitory Control Model (Green, 1998), Dynamic Systems Theory (DST).
