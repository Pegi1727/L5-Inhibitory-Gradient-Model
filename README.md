## Project Overview
This research investigates the 'Inhibitory Paradox' in multilingual speakers. The core hypothesis is that developmentally unstable languages (e.g., L4 Russian) produce stronger interference during the production of a new language (L5 Spanish) compared to highly entrenched, dominant languages (e.g., L3 English).

### 2. Statistical Findings
Preliminary analysis shows a significant difference in interference patterns:
- Russian (L4) Intrusions: High frequency, diverse domains.
- English (L3) Intrusions: Low frequency, rapid self-repair.
- Significance: χ2(1) = 34.78, p < .001 (Highly Significant).
