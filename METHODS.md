
# Methodology: L5 Inhibitory Gradient Analysis
‌
## 1. Coding & Categorization
All transcriptions are manually coded into three primary domains:
- **Lexical Intrusions:** Word-level substitutions.
- **Morphosyntactic Transfer:** Structural interference.
- **Phonological Carryover:** Accent and sound-level effects (e.g., palatalization).
‌
## 2. Temporal Analysis (Reaction Times)
Proxy measurements based on audio pause durations:
- **< 200 ms:** Rapid self-repair.
- **> 800 ms:** High inhibitory effort/cognitive load.
‌
## 3. Academic Framework
This study aligns with:
- **De Angelis (2007)** for multilingual transfer.
- **Rothman (2015)** for linguistic entrenchment models.
